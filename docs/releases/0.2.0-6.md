# Reelio 0.2.0-6

Unsigned developer preview for Linux and Windows x64. Source files and existing export destinations remain protected. These notes cover the local 0.2.0-4 through 0.2.0-6 updates since published Linux 0.2.0-3.

## Changes

- Full-work-area Subtitle Studio with all cues, three-column desktop layout, responsive stacking, playback-follow highlighting and scoped cue navigation. Text subtitle clips open source-preserving editable copies in Studio.
- Explicitly opening a validated project authorizes its existing individually referenced files without a second prompt. Missing files remain relinkable; directories and neighboring files are not granted. Only open projects you trust.
- Icon preview controls with tooltips: play/pause, stop-and-rewind, beginning/end, previous/next nominal frame, add chapter and previous/next chapter. Preview-only speed presets: 0.10, 0.25, 0.50, 0.75, 1, 2, 3, 4, 5 and 10x. Unsupported audio rates pause affected lanes instead of drifting out of sync.
- Floating notifications auto-hide after five seconds (errors after eight), with reading pauses.
- No duplicate window controls on Omarchy/Hyprland; Linux-style controls elsewhere on Linux and left-side macOS traffic-light styling.
- Quit Reelio and Ctrl/Cmd+W share the OS-close confirmation flow without redirecting to Studio. Confirmed quitting persists subtitle recovery drafts; exports, repair, update downloads and active model operations retain native close protection.
- Inspector toggle placement, export container/lane controls and workspace layout refinements from the annotation batches.

## Verification And Limits

Local Linux checks: 92 frontend unit tests, 128 workspace Rust tests (six explicit ignores), 11 desktop Rust tests (two display-dependent ignores), 33 desktop/mobile browser tests (one desktop-only skip), Clippy, formatting and production builds. Generated-H.264 WebKitGTK scrubbing/frame controls and a separate-data native compositor-close test pass. Browser tests mock native IPC; they are not Windows/macOS interactive qualification.

Frame stepping uses nominal source rate with a 25 fps fallback; variable-frame-rate steps remain approximate. Playback engines can reject extreme rates or mute their audio. Preview speed never changes export timing.

A fully cold isolated native Linux GStreamer cache reported one unavailable component; a warmed-registry native startup reports healthy backend/playback and zero missing components. This release does not claim universal cold-start or codec compatibility. The dedicated AppImage workflow separately requires a healthy actual packaged startup.

Windows installer interactive/runtime qualification and native macOS qualification remain open. Existing broader Ubuntu FFmpeg timing/audio and Windows/macOS relative-path CI failures are not represented as fixed. Packages are unsigned; SHA256SUMS verifies integrity, not publisher identity. FFmpeg/FFprobe remain external dependencies.

Save work before switching from an already-running older build. Per-user Linux installation does not forcibly close existing sessions or weaken system authorization.
