## Next Acceptance Milestones

1. Harden and qualify the existing import-to-export workflow on all three operating systems, including large files, disk full, race conditions, crash recovery, language/disposition edge cases, malformed inputs and native UI automation.
2. Extend native qualification of implemented audio mixing/language routing, subtitle positioning and chapter dragging; add standalone subtitle extraction and richer rendering controls.
3. Extend the implemented JPEG cover path with dedicated unknown-metadata/attachment preservation and broader round-trip qualification.
4. Add persistent batch scheduling, presets, templates and naming policies.
5. Add optional provider integrations and secure credential storage, followed by release accessibility/security/legal qualification.
